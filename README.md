# Simple Gallery Responsive Template

Адаптивный одностраничный шаблон галереи с красивым дизайном и размытым фоном. Готовые файлы находятся в папке `build` и готовы к использованию.

## Описание

Современный шаблон галереи с эффектом размытого фонового изображения и темным оверлеем. Проект включает главную страницу с навигацией и страницу галереи с сеткой изображений.

## ✨ Особенности

- Адаптивный дизайн
- Эффект размытого фонового изображения
- Темный оверлей для улучшения читаемости
- Страница галереи с сеткой изображений
- Минималистичный и элегантный дизайн
- Готовые к использованию файлы в папке `build`

## 🚀 Быстрый старт

1. Откройте файл `build/index.html` в браузере
2. Или используйте локальный веб-сервер:
   ```bash
   cd build
   python -m http.server 8000
   ```

## 🛠 Использование

### Настройка контента

Отредактируйте файлы в папке `build`:

- **index.html**: Главная страница с названием проекта
- **gallery.html**: Страница галереи
- **static/images/**: Замените изображения на свои

### Настройка изображений галереи

1. Замените изображения в `build/static/images/blocks/gallery/`
2. Обновите пути к изображениям в `gallery.html`
3. Измените названия и описания в `gallery.html`
